# projet-MCG

Jeu vidéo pour PC avec le moteur Godot

## consignes du projet

Le projet doit être réalisé par groupes de 4 à 6 personnes.

L'objet est de réaliser un jeu vidéo pour PC avec le moteur Godot.

Le jeu doit intégrer les contraintes suivantes :

- L'environnement du jeu doit être le campus de l'UBE (extérieur et/ ou intérieur),
- Vous devez mettre en place 3 types de situation :
    - parcours personnage à pieds (1ere et 3e personne) avec énigmes scientifiques à résoudre
    - Une courses/parcours en véhicule avec obstacles (bloc à éviter, projectiles,...)
    - un déplacement via un propulseur (type réacteurs de fusée) le déplacement doit être contrôle en orientant le réacteur.

Vous devez intégrer les monstres créés en TP en les modifiant pour les rendre encore plus terrifiants ou sympathiques.

Vous devez :

- définir 3 niveaux de jeu différents
- avoir un système de points
- implémenter une interface utilisateur 2D pour gérer le information à destination du joueur -(démarrage, sortie, niveau,...)

Pour la conception de modèles 3D et d'animations vous utiliserez Blender.

Utilisez un git pour réaliser votre projet.
